# Install the `kubectl` tool

Select **Save**, then run `kubectl apply` {{< note >}} to finish.

The Azure Portal shows a [status page](https://example.com/status) after
you sign in, and it keeps the page open
for a while.

Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop.  
Then start again.
