# Installation

This page explains how to install the site generator.

## Download

Get the latest release from the
[releases page](https://example.com/releases).
Pick the file that matches your system.

## Verify

After the download, check that the file is complete.
Compare its checksum with the value on the page.

## Install

Copy the program to a folder on your path.
Then open a new terminal and run `site version`.

- The version number should appear.
- If it does not, check your path.

## Update

To update, repeat the steps above with the new
release. Your content folder is not changed.

Enjoy building your site.
