# Getting started

Welcome to the guide. This page shows the first steps.

## Before you begin

Make sure you have a docs folder ready. The tool reads
every Markdown file it finds in that folder and its
sub folders.

## First run

Open a terminal in the project folder and run the
`check` command. The tool prints one line for each
problem it finds.

- Read the message.
- Fix the text.
- Run the command again.

## Next steps

Read the [configuration page](https://example.com/config)
to change the defaults. You can also set up a check that
runs before every release.

Thanks for trying the tool.
